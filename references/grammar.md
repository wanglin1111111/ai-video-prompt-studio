# 语法层：六要素决策表（模型无关）

> 六要素来自获奖作品验证过的结构：主体、场景环境、视觉风格、镜头动态、光影氛围、质量要求。
> 本层只回答"写什么、怎么选"，与任何模型无关；"怎么投喂"查 model-cards.md。

## 1. 主体（谁/什么在动）

- 一镜**只安排一个主动作主体**。多数模型多主体交互易崩（手部粘连、身份漂移）；确需多主体时，拆成正反打两镜。
- 主体描述三层：**身份**（性别年龄段/物种/材质）→ **可识别特征**（发型、服装颜色、道具——与角色圣经一致）→ **动作**（现在进行时，一个动词短语）。
- 反例→正例：
  - ✗ "一个女人在做饭" → ✓ "30岁女性，齐肩黑发，藏青色围裙，左手扶碗右手执筷快速搅拌，侧面站立"
- 主体动作幅度与时长匹配：5 秒内只够一个完整动作；"起身→走向窗→推窗"是三镜的事。

## 2. 场景环境（在哪）

- 远→近三层：**地域**（江南水乡/赛博都市/北欧森林）→ **具体场所**（石桥上/便利店门口）→ **环境细节**（雨后积水倒映霓虹、蒸汽从井盖冒出）。
- 环境细节给 2-3 个即可，多于 5 个会稀释主体权重。
- 场景跨镜复用时必须引用 `SCENE-*` 编号，措辞逐字复用圣经中的描述——同义改写会造成背景漂移。

## 3. 镜头动态（怎么拍）

**景别决策表**（信息密度 → 景别）：

| 想让观众看到 | 用景别 | 典型用途 |
|---|---|---|
| 环境全貌、人物渺小感 | 大远景/远景 | 开场定调、转场 |
| 主体全身与所处空间 | 全景 | 动作建立 |
| 膝盖以上，肢体语言 | 中景 | 对话、日常动作 |
| 胸部以上，情绪 | 近景 | 情绪反应 |
| 面部/物体细节 | 特写/大特写 | 关键道具、表情爆点 |

**运镜决策表**（叙事意图 → 运镜）：

| 意图 | 运镜 | 提示词写法示例 |
|---|---|---|
| 展示全貌 | 缓慢横移/摇 | "镜头自左向右缓慢横移" |
| 聚焦/强调 | 推 | "镜头缓缓推近至面部特写" |
| 揭示/离别 | 拉 | "镜头缓缓拉远，人物没入人群" |
| 跟随动感 | 跟拍/环绕 | "镜头环绕人物180度跟拍" |
| 客观冷静 | 固定机位 | "固定机位，无运镜" |

- 一镜一运镜。复合运镜（推完再摇）是崩坏高发区，确需复合时写明先后与幅度。
- 无运镜意图就写"固定机位"——留空会让模型自行加戏。

## 4. 光影氛围（什么光）

- 公式：**光源方向 + 光质 + 色温/色调**。例："左侧窗光，软光，暖金色黄昏调"。
- 常用安全组合：自然写实→柔光+自然色温；悬疑→侧逆光+青蓝低饱和；商业质感→三点布光+高调；复古→暖黄+褪色高光。
- 光影跨镜必须连续：同一场景相邻镜头的光位/色温冲突，观众立刻出戏。圣经里登记场景光照。

## 5. 视觉风格（什么画风）

- 风格三件套：**媒介**（实拍感/3D动画/水墨/定格动画）+ **参考语境**（90年代港片、吉卜力式田园、纪录片跟拍）+ **颗粒/质感**（35mm胶片颗粒、微距浅景深）。
- 全片风格关键词集中在一处定义（风格圣经），逐镜逐字复用，不要每镜即兴发挥同义词。
- 参考具体导演/作品名对效果有助益，但注意：部分模型对活人艺术家名字做了过滤，改用"某风格"描述词替代（见 gotchas.md）。

## 6. 质量要求（收尾增强）

- 通用增强词放句尾，控制在 3-5 个："8K、细节丰富、电影级画质、物理准确"。
- 无效增强词（模型已默认或无感）："best quality""masterpiece" 对视频模型基本无效，是图像模型时代的遗物。
- 与其堆增强词，不如把预算给前五要素的具体性。

## 组装顺序（中文母版）

```
[镜头语言] + [主体+动作] + [场景细节] + [光影] + [风格] + [质量词]
```

示例（中景·缓推）：
> 中景，镜头缓缓推近。30岁女性，齐肩黑发，藏青色围裙，在灶台前快速搅拌，蒸汽升起。江南老厨房，木窗棂透进晨光。左侧窗光软光，暖金色晨间调。实拍感，纪录片跟拍语境，35mm颗粒。8K，细节丰富，电影级画质。
