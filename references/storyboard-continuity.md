# 工作流层：分镜表与圣经系统

> 单镜头提示词生成器止步于"一镜一提示词"；本层解决它们不解决的事：多镜头之间**人物不换脸、场景不漂移、光照不跳变**。

## 1. 圣经系统（拍前登记）

从故事梗概提取，登记为结构化条目（JSON 分镜表中 `bibles` 字段）：

```json
{
  "characters": [
    {"id": "CHAR-1", "name": "林小满", "look": "30岁女性，齐肩黑发，左眉小疤",
     "wardrobe": "藏青色围裙、白色棉麻衬衫"}
  ],
  "scenes": [
    {"id": "SCENE-1", "name": "老厨房", "look": "江南老厨房，木窗棂，灶台，蒸汽",
     "lighting": "左侧窗光软光，暖金色晨间调"}
  ],
  "props": [
    {"id": "PROP-1", "name": "青花瓷碗", "look": "缠枝莲纹青花瓷碗，碗沿小缺口"}
  ],
  "style_bible": "实拍感，纪录片跟拍语境，35mm胶片颗粒，低饱和暖调"
}
```

三条纪律：
- **特征逐字复用**：镜头里引用 `CHAR-1` 时，把 look+wardrobe 原文抄进提示词（模型不认识你的编号，编号是给你和校验器用的）。同义改写=漂移。
- **风格圣经唯一**：全片风格在 `style_bible` 定义一次，逐镜整段复用。
- **光照挂在场景上**：场景光照是场景属性不是镜头属性；某镜要改光（如开灯），登记为派生场景 `SCENE-1b`。

## 2. 分镜表（shot list）

每镜一条记录：

```json
{
  "id": "S01",
  "model": "seedance-2.0",
  "duration_s": 5,
  "aspect_ratio": "16:9",
  "camera": {"size": "中景", "move": "固定机位"},
  "subject": "CHAR-1 在灶台前快速搅拌",
  "scene": "SCENE-1",
  "lighting": "继承 SCENE-1",
  "style": "继承 style_bible",
  "quality": ["8K", "电影级画质"],
  "audio": "环境声：炒菜滋滋声；无对白",
  "prompt_zh": "中景，固定机位。30岁女性，齐肩黑发，左眉小疤，藏青色围裙、白色棉麻衬衫，在灶台前快速搅拌，蒸汽升起。江南老厨房，木窗棂，灶台。左侧窗光软光，暖金色晨间调。实拍感，纪录片跟拍语境，35mm胶片颗粒，低饱和暖调。8K，电影级画质。",
  "i2v_start": null,
  "i2v_end": null,
  "continuity": ["CHAR-1", "SCENE-1"]
}
```

拆镜原则：
- **一镜一动作一信息**：一个镜头只传达一个叙事信息、一个主动作。
- **5 秒预算**：默认 5 秒一镜；"说完一句话+做完一个动作"通常要拆两镜。
- **正反打代替同框**：两人对话拆 A 说话近景 / B 反应近景，不要赌多主体。
- **转场三选一**：硬切（默认）、首尾帧（i2v_end → 下镜 i2v_start）、运镜转场（拉远接推近）。方言卡标注首尾帧强的模型（kling/seedance）优先用首尾帧。

## 3. 修订环（拍后迭代）

出片不达标时按缺陷类型回改，**只改责任层**：

| 症状 | 责任层 | 修法 |
|---|---|---|
| 人物换脸/服装漂移 | 圣经 | 特征描述太短，加可识别细节；或换带参考图/角色库的模型 |
| 背景漂移 | 圣经 | SCENE look 描述加细节，逐字复用检查 |
| 运镜没执行/乱动 | 方言层 | 查该模型运镜措辞怪癖；复合运镜拆单 |
| 动作没做完整 | 语法层 | 动作超出时长预算，拆镜 |
| 风格跳变 | 圣经 | style_bible 是否被某镜即兴改写 |
| 画面出现"不要XX"的东西 | 方言层 | 负面提示词被画进画面，改正向描述 |

每轮只修最大缺陷，重生成→再校验，直到 validate.py exit 0 且人工抽查通过。

## 4. 交付物清单

1. `shotlist.json`（机器可校验）
2. 可读表格：镜号/景别/运镜/画面/音频/时长/画幅
3. 待核对清单：所有 volatile 参数（时长档位、分辨率）+ 平台 UI 复核提示
4. 生成日志：每镜用了哪个模型哪个档位，方便回溯重跑
