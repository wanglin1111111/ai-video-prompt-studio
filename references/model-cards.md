# 方言层：模型卡（换模型=换卡，勿改语法层）

> **volatile 纪律**：各模型的时长档位/分辨率/价格随版本快速漂移。卡中标 `volatile` 的数值只用于初稿建议，交付前必须提示用户在平台当前 UI 复核。卡中只写"模型不可能猜到"的稳定怪癖；新增模型时复制本卡模板新建一节。

## seedance-2.x（即梦/字节）
- 模式：t2v + i2v + 首尾帧。
- 时长/画幅/分辨率：5s、10s 档为主；16:9、9:16、1:1、4:3 等；720p/1080p（volatile，以即梦当前 UI 为准）。
- 语言偏好：**中文原生**，中文语序自然即可，无需翻译腔。
- 负面提示词：无独立字段，避免在正文写"不要出现XX"——把不想要的东西写进正文等于邀请它进场；用正向描述替代。
- 已知怪癖：物理交互（流体、布料、重量感）表现强；对"镜头缓缓推近"这类运镜指令服从度高；多主体同框易身份漂移，拆镜。

### 实测记录（2026-08-27，即梦网页版 Agent 模式）
- **入口行为**：即梦 Agent 模式把"一段提示词"默认拆成 **4 张静帧候选**（图先于视频），需二次指令"选第 N 张生成 5 秒视频"才进入 i2v。分镜表的"每镜一图一视频"在即梦实际是"每镜一图×4 候选→选定→一视频"，成本翻倍计——S01 实测静帧 12 积分 + 视频 25 积分。
- **静帧验收（S01 落墨镜头）**：4/4 全部命中圣经关键项——墨落在**宣纸上**（gotchas 介质锚定三件套有效）、卷轴与纤维质感、低饱和黑白灰+朱砂红唯一点缀、留白克制。提示词六要素结构被完整理解（Agent 复述确认"宣纸质感、落墨动态、极简克制色彩调性"）。
- **已知偏差**：手部渲染偏"写实动漫混合"，非纯水墨动画质感——人物近景特写想保水墨感，需在主体层追加"手部以水墨笔触勾勒"类描述；或手部不入画（只拍笔与纸）。
- **计费单位**：积分。静帧约 3 积分/张，i2v 视频 25 积分/条（volatile，随会员档位浮动）。

## sora-2（OpenAI）
- 模式：t2v + i2v；原生音频（对白/音效/环境声同轨生成）。
- 时长：10-15s 档（volatile）；画幅横竖皆可。
- 语言偏好：英文提示词更稳；中文可用但音画同步的对白建议写英文再配音检查。
- 已知怪癖：对白与口型同步是其独占优势，写对白镜头时用 `dialogue:"台词"` 结构；真人写实风格强，动画风格相对弱；"cameo"机制与版权人物限制需注意平台政策。

## veo-3.x（Google）
- 模式：t2v + i2v；原生音频。
- 时长：8s 标准档（volatile）；720p/1080p。
- 语言偏好：英文更稳。
- 已知怪癖：音频提示词可与画面提示词分行写（`Audio:` 段）；对光影物理（水面反射、体积光） fidelity 高；提示词过长时优先截断尾部质量词而非前段主体。

## kling-2.x/3（可灵/快手）
- 模式：t2v + i2v + 首尾帧；含运动笔刷/运镜控制等结构化控制项。
- 时长：5s/10s（volatile）；1080p 常见。
- 语言偏好：中文原生。
- 负面提示词：有独立字段。
- 已知怪癖：首尾帧插值是强项——转场镜头优先考虑首尾帧而非纯文本描述；大幅度动作（跑跳打斗）服从度好；人物一致性可配合平台"角色库/ referenced image"功能，提示词侧仍需圣经编号锁特征。

## runway-gen-4（Runway）
- 模式：t2v + i2v；以 references 图保持角色/场景一致性是一大特色。
- 时长：5s/10s（volatile）；无原生音频。
- 语言偏好：英文。
- 已知怪癖：单主体短动作最稳；提示词宜短（一两句核心），长提示词收益递减；一致性靠参考图而非长文本描述，圣经应配参考图槽位。

## pixverse-v5（爱诗）
- 模式：t2v + i2v + 首尾帧；特效模板库丰富。
- 时长：5s/8s（volatile）。
- 语言偏好：中文可用，英文更稳。
- 已知怪癖：动漫/风格化强势，写实人脸较 others 弱；内置效果模板（如变身类）绕过常规提示词逻辑，用模板时正文只需描述主体。

## 适配工作法

1. 用户未指定模型时，按用途推荐：中文营销竖屏→seedance/kling；带对白短片→sora-2 或 veo；动漫/特效玩法→pixverse；角色一致性优先→runway(+参考图) 或 kling(角色库)。
2. 跨模型移植提示词时：语法层六要素不动，重写方言相关项（语言、音频段、负面字段、运镜措辞按怪癖调整）。
3. 每次实际投喂后，把新发现的怪癖回填进对应卡片——卡片是活文档。
